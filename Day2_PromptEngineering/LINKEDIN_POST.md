**Building Multi-Turn Agentic AI Systems with Google Gemini**

I'm excited to share my latest project: an enterprise-grade dashboard demonstrating multi-turn agentic AI with real-time function calling.

**What I Built:**
A professional AI agent system that autonomously chains multiple API calls to solve complex queries. The agent intelligently decides which tools to use and in what sequence - no hardcoded logic, just pure AI reasoning.

**Key Technical Features:**
- Multi-turn agent execution with Google Gemini Flash Lite
- Native function calling (not prompt engineering)
- Real-time API integrations: Weather, Currency, Geographic data
- Special support for Indian Rupees (INR) conversion
- Enterprise-grade UI with modern design patterns

**Architecture Highlights:**
The system uses three integrated tools that the AI agent can call autonomously:
1. Live weather data (wttr.in API)
2. Currency conversion (ExchangeRate-API)
3. City intelligence database

**Example Query:**
"What's the weather in Mumbai and how much is 100 USD in INR?"

The agent automatically:
- Calls the weather API for Mumbai
- Calls the currency API for USD to INR conversion
- Synthesizes the information into a coherent response

**Technologies Used:**
Python | Gradio | Google Gemini API | REST APIs | Multi-Agent Systems

**What I Learned:**
- Building autonomous AI agents that can reason about tool usage
- Implementing multi-turn conversation loops
- Integrating live APIs with AI function calling
- Creating production-ready enterprise UIs

This project demonstrates the power of agentic AI - systems that can autonomously plan, execute, and adapt to solve complex problems.

**Live Demo:**
The dashboard runs locally and provides real-time responses to natural language queries about weather, currency, and city information.
