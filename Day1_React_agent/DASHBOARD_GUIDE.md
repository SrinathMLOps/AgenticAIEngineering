# 🎨 Dashboard Guide - Visualize Your Agent's Thinking

## What is the Dashboard?

The dashboard is a **beautiful web interface** that lets you watch your AI agent think and work in real-time. Instead of just seeing text in a terminal, you get:

- **Color-coded steps** - See THINK, ACT, OBSERVE, and FINISH phases clearly
- **Real-time display** - Watch the agent's reasoning process unfold
- **Token tracking** - Monitor API usage and costs for each step
- **Interactive UI** - Easy-to-use web interface with example queries

Think of it like watching a chef cook through a kitchen window - you see every step of the process, not just the final dish!

---

## 🚀 Quick Start

### Step 1: Install Dependencies

```bash
cd simple
pip install -r requirements.txt
```

This will install Gradio (the dashboard framework) along with all other dependencies.

### Step 2: Set Up Your API Key

Make sure you have a `.env` file with your API key:

```bash
ANTHROPIC_API_KEY=your_actual_api_key_here
MODEL=claude-sonnet-4-20250514
MAX_STEPS=15
```

### Step 3: Launch the Dashboard

```bash
python dashboard.py
```

You'll see output like:
```
============================================================
🚀 Starting ReAct Agent Dashboard...
============================================================

📱 Open your browser and go to: http://localhost:7860
🔑 Make sure ANTHROPIC_API_KEY is set in your .env file

============================================================
```

### Step 4: Open in Browser

Go to **http://localhost:7860** in your web browser. You'll see a beautiful interface!

## 📊 Understanding the Dashboard Output

### Summary Card (Top)

```
╔═══════════════════════════════════════════════╗
║ 🤖 Agent Execution Summary                    ║
╠═══════════════════════════════════════════════╣
║  5         2,847        1,234        $0.0234  ║
║  Steps     Input       Output       Cost      ║
║           Tokens      Tokens       (USD)      ║
╚═══════════════════════════════════════════════╝
```

This shows you:
- **Steps**: How many reasoning cycles the agent took
- **Input Tokens**: Context sent to the API
- **Output Tokens**: Response generated by the API
- **Cost**: Estimated cost in USD (based on Claude pricing)

### Step-by-Step Display

Each step shows up to 4 phases:

#### 1. 🤔 THINK (Blue Box)
```
┌─────────────────────────────────────────┐
│ 🤔 THINK                                │
│ I need to calculate 25 * 47 first,     │
│ then add 183 to the result.            │
└─────────────────────────────────────────┘
```
**What it means**: The agent's internal reasoning about what to do next.

#### 2. 🔧 ACT (Orange Box)
```
┌─────────────────────────────────────────┐
│ 🔧 ACT: calculator                      │
│ {                                       │
│   "operation": "multiply",              │
│   "a": 25,                              │
│   "b": 47                               │
│ }                                       │
└─────────────────────────────────────────┘
```
**What it means**: The agent decided to use a tool. Shows the tool name and parameters.

#### 3. 👁️ OBSERVE (Green Box) or ❌ ERROR (Red Box)
```
┌─────────────────────────────────────────┐
│ 👁️ OBSERVE                              │
│ 1175                                    │
└─────────────────────────────────────────┘
```
**What it means**: The result returned from the tool. Green for success, red for errors.

#### 4. ✅ FINAL ANSWER (Gradient Green Box)
```
╔═════════════════════════════════════════╗
║ ✅ FINAL ANSWER                         ║
╠═════════════════════════════════════════╣
║ The calculation 25 * 47 + 183 equals    ║
║ 1,358.                                  ║
╚═════════════════════════════════════════╝
```
**What it means**: The agent has completed the task and provides the final answer.

## 🏗️ How the Dashboard Works (Technical)

### Architecture

```
User Input (Web Browser)
    ↓
Gradio Interface
    ↓
DashboardAgent.run_with_logging()
    ↓
┌───────────────────────────────────────┐
│ 1. Initialize API client & memory     │
│ 2. For each step (up to MAX_STEPS):  │
│    • Call Claude API with tools       │
│    • Log THINK phase                  │
│    • If tool_use:                     │
│      - Log ACT phase                  │
│      - Execute tool                   │
│      - Log OBSERVE phase              │
│    • If end_turn:                     │
│      - Log FINISH phase               │
│      - Break loop                     │
│ 3. Format all steps as HTML          │
└───────────────────────────────────────┘
    ↓
Beautiful HTML Output
    ↓
Display in Browser
```

### Key Components

**1. DashboardAgent Class**
- Wraps the original `run_agent()` function
- Captures every step for display
- Tracks token usage and timing

**2. Step Logging**
- Each API call is logged with:
  - Thinking text
  - Tool calls and parameters
  - Tool results
  - Token counts

**3. HTML Formatting**
- Converts step data into beautiful HTML
- Color-codes different phases
- Makes it easy to follow the agent's logic

**4. Gradio Interface**
- Provides the web UI
- Handles user input
- Displays formatted output

## 🎨 Customization Options

### Change the Port

Edit `dashboard.py`:
```python
demo.launch(
    server_port=7860,  # Change this to 8080, 3000, etc.
)
```

### Enable Public Sharing

To create a public link (shareable over the internet):
```python
demo.launch(
    share=True,  # Creates a public URL
)
```

You'll get a URL like: `https://abc123.gradio.live`

**⚠️ Security Warning**: Anyone with this link can use your API key! Only enable for demos.

### Customize Colors

The dashboard uses these color schemes:

- **THINK**: Blue (`#f0f7ff`, `#2563eb`)
- **ACT**: Orange (`#fff7ed`, `#ea580c`)
- **OBSERVE**: Green (`#f0fdf4`, `#16a34a`)
- **ERROR**: Red (`#fef2f2`, `#dc2626`)
- **FINISH**: Gradient Green

Edit the `_format_output()` method to change colors.

### Add More Stats

You can track additional metrics by modifying the `DashboardAgent` class:

```python
step_info = {
    "step": step,
    "stop_reason": response.stop_reason,
    "content": [],
    "tokens": {
        "input": response.usage.input_tokens,
        "output": response.usage.output_tokens
    },
    # Add your custom metrics here
    "timestamp": time.time(),
    "model": MODEL,
}
```

## 🐛 Troubleshooting

### "Module 'gradio' not found"

**Solution**: Install Gradio
```bash
pip install gradio>=4.0.0
```

### "Error: ANTHROPIC_API_KEY not found"

**Solution**: Create a `.env` file in the `simple/` folder:
```
ANTHROPIC_API_KEY=sk-ant-xxxxx
```

### Dashboard shows blank page

**Solution**: Check the terminal for error messages. Usually this means:
- Missing API key
- Network issues
- Browser cache (try Ctrl+F5)

### "Address already in use"

**Solution**: The port 7860 is busy. Either:
- Stop the other process using that port
- Change the port in `dashboard.py`

### Dashboard is slow

**Solution**: 
- Reduce `MAX_STEPS` in `.env`
- Use a faster model
- Check your internet connection

## 📈 Advanced Features

### Save Conversation History

Add this to save each run:

```python
import json
from datetime import datetime

def save_run(task, steps):
    timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
    filename = f"logs/run_{timestamp}.json"
    
    with open(filename, "w") as f:
        json.dump({
            "task": task,
            "steps": steps,
            "timestamp": timestamp
        }, f, indent=2)
```

### Compare Multiple Runs

Create a comparison view to see how the agent approaches the same task differently:

```python
def compare_runs(task1_steps, task2_steps):
    # Side-by-side comparison
    html = "<div style='display: grid; grid-template-columns: 1fr 1fr;'>"
    html += f"<div>{format_steps(task1_steps)}</div>"
    html += f"<div>{format_steps(task2_steps)}</div>"
    html += "</div>"
    return html
```

### Add Authentication

Protect your dashboard with a password:

```python
demo.launch(
    auth=("username", "password"),  # Simple auth
)
```

### Export to PDF

Add a button to export the agent run as a PDF report:

```python
from weasyprint import HTML

def export_pdf(html_content):
    HTML(string=html_content).write_pdf("agent_run.pdf")
```
